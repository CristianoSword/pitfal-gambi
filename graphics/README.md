# Graphics Directory

Esta pasta é reservada para arquivos de imagens/sprites do jogo Pitfall! (PNG, JPG, SVG, etc.).

No momento, o jogo utiliza renderização procedurar pixel-art retro via HTML5 Canvas, garantindo que o jogo rode instantaneamente sem dependência de assets externos.
Caso adicione sprites customizados nesta pasta (ex: `harry.png`, `croc.png`, `log.png`), eles poderão ser integrados no canvas.
